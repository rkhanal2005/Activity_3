# Activity 3 Building GUI

In this activity, you will begin designing the Store GUI application by creating detailed blueprints 
for its interface. These blueprints should outline the layout and placement of all necessary 
elements. Using the ER diagram and tables from Activity 2 as a reference, clearly indicate 
where each piece of data will be displayed in the GUI. This step will serve as the foundation for 
the application's development, ensuring that all required information is presented effectively.
